Sobre nuestro proyecto

Nuestro proyecto combina tecnologías avanzadas de inteligencia artificial con una base de conocimiento en Prolog para proporcionar identificaciones precisas de aves. Utilizamos Azure OpenAI para analizar imágenes y extraer características clave, que luego se validan contra nuestra base de datos especializada.

La biodiversidad de Costa Rica es uno de sus mayores tesoros, y las aves representan una parte significativa de esta riqueza natural. Nuestro objetivo es hacer que la identificación de aves sea accesible para todos, desde ornitólogos experimentados hasta entusiastas principiantes y turistas que visitan este hermoso país.

¿Cómo funciona?

Nuestra aplicación utiliza un enfoque de dos pasos para la identificación de aves:

  1. Análisis de IA: Cuando subes una imagen, nuestro sistema basado en Azure OpenAI analiza la imagen para identificar el ave y extraer características clave como color, forma y patrones.
  2. Validación con base de conocimiento: Los resultados del análisis de IA se validan contra nuestra base de conocimiento en Prolog, que contiene información detallada y verificada sobre las aves de Costa Rica.
  3. Resultados combinados: Te presentamos los resultados combinados, mostrando tanto la información identificada por la IA como la información validada de nuestra base de conocimiento.
